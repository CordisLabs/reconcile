# 16 · Attention Is All You Need（Vaswani et al., 2017）

缩放点积注意力 + 多头注意力，前向与**手写反向传播**。只按论文公式 (1)(2) 实现，
未参考任何第三方复现代码。

## 论文报告

WMT 2014 EN-DE 上 BLEU 27.3（big 模型），8×P100 训练 3.5 天（论文 §6.1）。

## 本仓实测

**不复现 BLEU**——没有 WMT14、没有 GPU，而且本切片只到注意力块。改测三个可判定的性质：

| 检验 | 判据 | 实测 |
|---|---|---|
| 多头注意力解析梯度 vs 有限差分 | 288 参数，`\|a−n\| ≤ atol + rtol·\|n\|` | max_abs **4.0e-10**，max_rel **2.5e-8** |
| 置换等变性（本切片无位置编码） | 精确相等 | max\|Δ\| **5.6e-17** |
| ∂L/∂b_k ≡ 0（softmax 平移不变性） | 结构性零 | **6.3e-17** |

## 差异归因

- **BLEU 未测**：输入是合成张量，没有 BPE、位置编码、masking 与训练管线。这些属于
  `17_annotated_transformer`。
- 这三个检验能证明的是**实现与论文公式一致**，不能证明**模型会翻译**。把这两件事混为
  一谈，是同类仓库最常见的夸大方式。
- 顺带一个真实发现：注意力对 key 偏置的梯度**恒等于 0**——因为 dS 的每一行和为 0
  （softmax 对整行平移不变），对 key 求和必然抵消。这也解释了为什么纯相对误差的梯度
  校验会在正确的实现上报 1.0 的"误差"：那是有限差分的舍入噪声被结构零除爆了。
