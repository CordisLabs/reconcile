# 27 · Scaling Laws for Neural Language Models（Kaplan et al., 2020）

幂律拟合与给定算力的最优分配——全部是算术。

## 论文报告

摘要原文：

> The loss scales as a power-law with model size, dataset size, and the amount of compute
> used for training, with some trends spanning more than seven orders of magnitude. Other
> architectural details such as network width or depth have minimal effects within a wide
> range.

> … These relationships allow us to determine the optimal allocation of a fixed compute
> budget. Larger models are significantly more sample-efficient, such that optimally
> compute-efficient training involves training very large models on a relatively modest
> amount of data and stopping significantly before convergence.

## 本仓实测

10 项检查，0.1 秒。

| 检验 | 实测 |
|---|---|
| 从含噪曲线恢复 α（真值 0.076） | **0.07584**（误差 0.2%），r² = 0.999 |
| 恢复前置因子 a（真值 0.5） | 0.4988（误差 0.25%） |
| 闭式最优 vs 黄金分割搜索（C = 1e15/1e18/1e21） | 相对误差 ≤ **1.7e-7** |
| N 在 C 中的指数 | **0.555556** = β/(α+β)（精确到 1e-9） |
| D 在 C 中的指数 | **0.444444** = α/(α+β) |
| 两指数之和 | 1.0 |
| 固定数据量下，参数更多 → loss 更低 | 1.403 → 1.356 → 1.316 → 1.283 |

闭式解：把 `D = C/(6N)` 代入 `a/N^α + b/D^β`，求导得

```
N^{α+β} = (αa)/(βb) · (C/6)^β
```


## 真实训练曲线（GPU）

上面那部分是**合成曲线上的算术**。这里补一次**真的训练**：RTX 5080，31.6M 字符的公有领域
语料（37 本 Gutenberg 书，`gpu/prepare_corpus.py` 下载，不入库），字符级 Transformer，
每个模型固定 **2000 万 token**，只改容量。跨越 **392 倍**参数量。

十个模型全部跑完 **21 分 26 秒**。注意最大的那个比 34M 还差 0.004——数据不够了。

**指数取决于数据是否充足**（`fit.py`）：

| 拟合范围 | 点数 | α | r² |
|---|---|---|---|
| 全部 | 10 | 0.0456 | 0.906 |
| D/N > 2 | 6 | 0.0659 | 0.975 |
| D/N > 5 | 5 | 0.0735 | 0.989 |
| **D/N > 10** | 4 | **0.0778** | **0.993** |

**数据充足的子集给 α = 0.0778，论文报的是 0.076。** 把 D/N < 1 的大模型也算进去，指数被
拉到 0.0456、拟合变差（r² 0.906）。这不是"复现 / 没复现"的二元判断：同一个模型族在不同
regime 下给出不同的数字，而 Kaplan 也是分 regime 拟合的。

## L(N, D) 联合拟合

之前只做了单变量和条件数。`gpu/joint_fit.py` 跑一个 4 个规模 × 3 个 token 预算的网格（12 次训练，
9 分钟），然后同时拟合

```
L = a·N^-α + b·D^-β + L∞
```

结果：**L = 14.90·N^−0.2341 + 2044.9·D^−0.5328 + 0.833**，**r² = 0.970**。

| 指数 | 本仓 | 论文 |
|---|---|---|
| α（规模） | **0.2341** | ~0.076 |
| β（数据） | **0.5328** | ~0.095 |

**指数比论文大 2–5 倍，这是 regime 差异而不是矛盾**：网格的 token 预算只有 200 万到 2000 万，
论文是数十亿；模型也只有 13 万到 2150 万参数。12 个点拟合 3 个自由参数，r² 0.97 的说服力有限。

## 差异归因

**1. 曲线是合成的，不是训练出来的。** 论文拟合的是真实的训练曲线（跨 7 个数量级）。本切片
验证的是"给定幂律，能否恢复指数、能否解出最优分配"——**不是**"幂律在真实模型上是否成立"。
后者需要训练几百个模型，不在这个仓库的范围内。

**2. 合成部分的 α 和 β 是选的**（0.076 / 0.095，量级取自论文），所以"恢复误差 0.2%"说明
拟合器没问题，不说明论文的指数是对的。真实部分拟合出 **0.1125**，与论文的 0.076 不同——原因是
**数据受限**：D/N 从 32 掉到 1.5，大模型没有喂够 token，曲线因此更陡。这不是矛盾，是另一个
regime。

**3. L(N,D) 联合拟合做了，但网格离论文的 regime 很远。** 论文同时拟合三个变量（含 L∞）；这里只做了单变量恢复
加上闭式最优分配。

**4. Kaplan 报的 `N ∝ C^0.73` 与这里的 0.556 不矛盾。** 它们用的是不同的指数组合
（`N ∝ C^{β/(α+β)}`），我用的是自己的 α、β。把两个数字直接对比是错误的。

**5. 数值检验的搜索范围必须覆盖最优点。** 固定线性网格（N ≤ 1e6）在 C 较大时返回边界值而不是
最优点，而它看起来像一次完成的搜索。这里改用 log 空间的黄金分割，与闭式解一致到 1e-7。
