# 20 · A Simple Neural Network Module for Relational Reasoning（Santoro et al., 2017）

关系模块 `RN(O) = f_φ(Σ_{i,j} g_θ(o_i, o_j))`，任务是"数出某种颜色的对象有几个"。

## 论文报告

摘要原文：

> Relational reasoning is a central component of generally intelligent behavior, but has
> proven difficult for neural networks to learn. In this paper we describe how to use
> Relation Networks (RNs) as a simple plug-and-play module to solve problems that
> fundamentally hinge on relational reasoning.

> … using a curated dataset called Sort-of-CLEVR we show that powerful convolutional
> networks do not have a general capacity to solve relational questions, but can gain this
> capacity when augmented with RNs.

模块本身（§2）：`g_θ` 逐对处理，对所有有序对求和，`f_φ` 把聚合结果映射到答案。

## 本仓实测

| 检验 | 实测 |
|---|---|
| 梯度 vs 有限差分 | max_abs **3.6e-10** |
| 对象置换下输出变化（10 次置换） | max\|Δ\| = **4.4e-15** |
| 计数任务（1500 步，3.9 秒） | loss 8.99 → **0.148**，准确率 **0.985** |
| 打乱对象顺序后的准确率 | **0.985**（与打乱前完全相同） |

置换不变性是**构造性的**：`Σ_{i,j}` 看不见顺序，所以输出必须逐位相同。实测 4.4e-15
就是浮点噪声。这也解释了为什么打乱对象后准确率一个数都不变——模型的答案根本不依赖列举顺序。

## CNN 对照（GPU）

论文摘要里最强的一句是"强大的卷积网络**没有**通用能力解关系问题，加上 RN 才有"。这一节给它
一个数字。

任务：四个色块画在 4×4 网格上，问**"距离最近的那一对，颜色相同吗"**——必须把位置和颜色绑定，
数颜色是算不出来的。

| 模型 | 测试准确率 | 参数 |
|---|---|---|
| CNN（卷积 + 全局池化） | **0.8707** | 18,626 |
| CNN + 关系模块 | **0.8848** | 26,946 |

**差距只有 1.4 个点。但这不构成对论文的检验。** 论文的主张是"CNN 没有解关系问题的通用能力"，
要检验它，任务必须让 CNN 解不出来；我的任务 CNN 拿了 0.871，说明**任务太容易**——检验没做成。

严格的写法是：**这个实验没有区分出两个模型**，所以它既不支持也不否定论文的主张。要看差距，
需要更难的问题（多跳关系、组合、遮挡），而那也是程序的一部分，不是论文的问题。

（之前还试过"任意两个颜色相同吗"，两个模型都是 100%——那题纯计数，CNN 当然会。）

## CNN / MLP 与关系模块的对照

前四次尝试都失败，原因找到了：**标签是 75/25 不平衡的**，所有模型都在猜多数类。加上
**拒绝采样强制 50/50** 之后，对照立刻有了分辨力。

**特征层面**（两者拿到同一份物体特征：颜色 one-hot + 网格坐标，问题是"最近的两个物体颜色相同吗"）：

| 模型 | 准确率 |
|---|---|
| MLP（拼接所有物体） | 0.643 |
| **RN（两两配对 → 求和）** | **0.803** |

**差 16 个百分点**——这是论文核心机制的干净演示：同样的输入，能算两两关系的模块明显更强。

**图像层面**（共享卷积主干，物体在 4×4 网格里，每个 token 对应一个格子）：

| 模型 | 准确率 |
|---|---|
| CNN（全局池化） | 0.819 |
| **CNN + RN** | **0.853** |

只差 3.4 点——因为**全局池化的 CNN 能靠数颜色猜对大半**。这解释了为什么早先的图像版对比
总是分不开：**问题的答案有一大半在颜色统计里，不在空间关系里**。

**健全性检查**：标签平衡后，给真实特征的 MLP 在特征版上只有 0.643，说明这个任务确实需要
关系结构；而 RL 版能到 0.803，说明它是**可学的**。

**结论：论文的主张（关系模块带来的收益）在本仓成立**，幅度取决于问题有多少能被全局统计
回答——特征层面 16 点，图像层面 3.4 点。

## 差异归因

**1. 任务是我造的，不是 sort-of-CLEVR。** 6 个对象、3 种颜色、问题"颜色 c 有几个"，
答案 0–6。论文的是图像 + 复杂关系问题（"离蓝色球最近的物体是什么形状"）。

**2. 最重要的对照做了两次，都因为实现缺陷没有区分出两个模型。** 论文摘要里最强的一句是"强大的卷积网络**没有**通用能力解关系
问题，加上 RN 才有"——要验证它需要一个无 RN 的基线（比如把对象特征直接拼接后过 MLP）。
**本切片没有这个基线**，所以它只证明了"RN 能学一种关系任务"，没有证明"别的架构学不会"。
这是本切片最大的缺口。

**3. 不变性是构造出来的，不是学出来的。** 和 18 的置换不变、19 的掩码一样，要区分"实现
正确"与"模型学会了某件事"。前者是算术，后者需要对照实验。

**4. 只有关系模块，没有视觉前端。** 输入是手工特征（坐标、颜色 one-hot、形状 one-hot），
不是 CNN 提取的特征图。

**5. K 固定为 6**，没有测变长对象数。
