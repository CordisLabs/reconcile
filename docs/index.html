#论文可验证的指标状态
01Keeping Neural Networks Simple by Minimizing the Description Length of the Weights — Hinton & van Camp <https://www.cs.toronto.edu/~hinton/absps/colt93.pdf>
1993
✅ 二部码长在 σ 网格上有内点极小；**固定模型时 MDL 选的 σ 比测试最优偏小**（代价 1.02–1.49×，随先验尺度）；跨 degree 选择代价 1.116×；噪声权重部分：解析梯度 <1e-6，噪声水平被学成内点最优（总码长 193→4.85 nats）完成
02A Tutorial Introduction to the Minimum Description Length Principle — Grünwald <https://arxiv.org/abs/math/0406077>
2004
✅ NML 后悔值：R(1)=1.0000 … R(1e5)=**8.6330**；斜率 **0.5**（误差 <0.02）；Kraft 和 = **1.000000000000000**；偏移收敛到 **0.5·log₂(π/2)=0.3258**（实测 0.3282）。只做 NML，未做 two-part / prequential / AIC-BIC 对比完成
03The First Law of Complexodynamics — Aaronson <https://scottaaronson.blog/?p=762>
2011
✅ 上界论证：shortcut 74→88 bits vs 状态 1272→12128 bits。**猜想经验检查**：complextropy = 压缩(细)−压缩(粗)，在咖啡自动机上从 −12 升到峰值 **757**，终点 633——**上升明确、下降只有 16%**，只部分支持原文的 rise-and-fall完成
04Quantifying the Rise and Fall of Complexity in Closed Systems: The Coffee Automaton — Aaronson et al. <https://arxiv.org/abs/1405.6903>
2014
✅ 按论文定义复现：熵 90→1516；复杂度 111→537→110。**双压缩器对照**：LZ77 与 order-2 的峰值都在 **1,333,333 步**（537 / 211.4 字节），所以「先升后降」**对压缩器稳健**；但「降回起点」只有 LZ77 成立（order-2 终点 20.7 vs 起点 2.6）完成
05Kolmogorov Complexity and Algorithmic Randomness — Shen, Uspensky, Vereshchagin <https://www.lirmm.fr/~ashen/kolmbook-eng-scan.pdf>
—
✅ Huffman：英文样例 H=4.2984 / L=4.3366（54.21% of 定长 8 bit），H ≤ L < H+1、Kraft 取等 <1e-12、前缀无关、往返一致；偏斜源 L=1.1700 vs 定长 3 bit。**未做**：算术编码与 NCD（指标里的后两条）完成
06Machine Super Intelligence — Legg <https://www.vetta.org/documents/Machine_Super_Intelligence.pdf>
2008
✅ Υ 有界；三档 agent 排序成立（随机 **0.5024** / 最优固定 **0.5145** / oracle **0.9412**）；归一化 Υ 对编码平移严格不变（c=0…16，差 <1e-12），未归一化按 2^(−c) 缩放。**K 不可计算**，用有限环境类代替；原 PDF 取不到，公式未逐字核对完成
07The Unreasonable Effectiveness of RNNs — Karpathy <https://karpathy.github.io/2015/05/21/rnn-effectiveness/>

08Understanding LSTM Networks — Olah <https://colah.github.io/posts/2015-08-Understanding-LSTMs/>
